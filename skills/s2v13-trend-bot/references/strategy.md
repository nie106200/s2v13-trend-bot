# 策略完整规格

## 1. 品种池（19 个）

| 类别 | 品种 | 入场 | 出场 |
|---|---|---|---|
| 核心 | BTC ETH XRP BNB SOL ADA TRX LINK DOT | 三线排列 | 死叉 HR |
| meme/高波动 | DOGE PEPE ZEC | 道氏破前高 | 日线趋势线 |
| 高波动（三线） | SAND MANA NEAR SEI ALGO HBAR UNI | 三线排列 | 死叉 HR |

## 2. 指标

```
EMA8 / EMA100 / EMA200（4H 收盘）
ATR60（4H，Wilder 平滑）
pivot high/low（左右各 3 根，滞后 3 根后才可用 → 无未来函数）
日线趋势线：最近两个已确认 pivot low 连线，shift(1)
月波动率：日收益的 30 日滚动标准差
```

## 3. 入场

**核心品种（三线排列）**
```
EMA8 > EMA100 > EMA200  且  close > EMA100
```

**meme 品种（道氏突破）**
```
close > 最近已确认 pivot high  且  前一根 close <= 该 pivot
且  close > EMA100
```

## 4. 止损（F3 动态止损）

```
stop = max( close − 3×ATR60 ,  close × (1 − 1.2×回调深度) )
```

`回调深度` = 该品种历史「pivot high → 下一个 pivot low」跌幅的中位数。

**为什么需要 F3**：不同品种波动差异极大（BTC ATR 1.66% vs PEPE 3.75%），
统一 3N 止损对高波动品种过窄、会被日常噪音打掉。F3 把止损放宽到
「该品种自己的正常回调」之外。**组合层面实测：加 F3 终值 +57~60%。**

## 5. 出场

**核心（HR 规则）**：死叉时
```
若 (持有期间最大浮盈 ≥ 10%) 且 (close > EMA200) 且 (尚未减半)  → 减半仓
否则 → 全部平仓
```

**meme（道氏）**：close < 日线趋势线（最近两个 pivot low 连线）→ 全部平仓

## 6. 24 小时补丁

入场后前 6 根 4H K 线（24h）内**只允许止损出场**，不允许死叉/趋势线出场。
目的：避免刚开仓就被小幅噪音洗掉。

## 7. 仓位

```
权重_i ∝ 1 / σ_i（σ = 30 日波动率）
归一化使 BTC = 1.0（最低波动 → 最大仓位）
单笔 ≤ 50% × 权益
总名义 ≤ 150% × 权益
杠杆 3× 逐仓
```

## 8. 三闸门

| 闸门 | 规则 | 实测效果 |
|---|---|---|
| 熊市闸门 | BTC 收盘 < 200 日均线 → 不开新仓 | 终值 +39%、MDD −9.7pp |
| 回撤闸门 | 账户回撤 ≥20% → 只开价格在自身 EMA200 上方的品种 | MDD −6.8pp |
| 品种分级 | 广度（几个品种在自己 200 日线上方）门槛：核心 0% / 卫星 50% / 高波动 70% | MDD −16.8pp、Calmar +34% |

## 9. 周亏补丁

同一品种一周内亏损 2 单 → 该品种本周不再开新仓（下周一自动恢复）。
