# 策略规格（框架版）

> 本仓库公开的是**框架与方法论**，具体参数值在私有配置文件 `config.json` 中。
> 仓库内 `config.example.json` 提供的是**中性起始值**（非最优），请自行调参。

## 1. 品种池（分层）

| 类别 | 数量 | 入场方式 | 出场方式 |
|---|---|---|---|
| 核心（大盘） | n_core | 三线排列 | 死叉 HR |
| meme / 高波动 | n_meme | 道氏突破前高 | 日线趋势线 |
| 其他高波动 | n_alt | 三线排列 | 死叉 HR |

分层的目的：**同一套规则在不同波动特征的品种上表现差异极大**，
把 meme 币单独出来用道氏逻辑，是实测下来唯一能吃到其「拉升—震荡—再拉升」结构的方式。

## 2. 指标（全部无未来函数）

```
EMA_fast / EMA_mid / EMA_slow   周期见 config.entry
ATR(ATR_LEN)                     Wilder 平滑
pivot high/low                  左右各 PIVOT_K 根，滞后 PIVOT_K 根后才可用
日线趋势线                       最近两个已确认 pivot low 连线，shift(1)
月波动率                         日收益的 30 日滚动标准差
```

**关键纪律**：pivot 必须等确认（滞后 K 根）才能用。**未滞后的 pivot 会造成前视偏差**，
这是趋势跟踪回测里最常见的「虚假高收益」来源。

## 3. 入场

**三线排列（核心 + 高波动）**
```
EMA_fast > EMA_mid > EMA_slow   且   close > EMA_mid
```

**道氏突破（meme）**
```
close > 最近已确认 pivot high   且   前一根 close <= 该 pivot
且   close > EMA_mid
```

## 4. 止损（动态止损）

```
stop = max( close − ATR_MULT × ATR ,  close × (1 − PULLBACK_MULT × 回调深度) )
```

`回调深度` = 该品种历史「pivot high → 下一个 pivot low」跌幅的中位数。

**为什么不是固定倍数止损**：不同品种 ATR 差异可达 2~3 倍，固定倍数对高波动品种过窄，
会被日常噪音打掉。动态止损把止损放到「该品种自己的正常回调」之外。

## 5. 出场

**核心（HR 规则）**：死叉时
```
若 (持有期间最大浮盈 ≥ MFE_THRESHOLD) 且 (close > EMA_slow) 且 (尚未减半)  → 减半仓
否则 → 全部平仓
```

**meme（道氏）**：close < 日线趋势线 → 全部平仓

## 6. 最小持仓补丁

入场后前 MIN_HOLD_BARS 根 K 线内**只允许止损出场**，不允许死叉/趋势线出场。
目的：避免刚开仓就被小幅噪音洗掉（实测能减少约 15% 的无效交易）。

## 7. 仓位

```
权重_i ∝ 1 / σ_i（σ = 30 日波动率）
归一化使锚定品种（默认 BTC，波动最低）= 1.0
单笔 ≤ MAX_POS_PCT × 权益
总名义 ≤ GROSS_CAP × 权益
杠杆 LEVERAGE × 逐仓（TD_MODE）
```

## 8. 三闸门

| 闸门 | 规则 | 实测效果 |
|---|---|---|
| 熊市闸门 | 锚定品种收盘 < N 日均线 → 不开新仓 | 终值 +39%、回撤 −9.7pp |
| 回撤闸门 | 账户回撤 ≥ DD_TRIGGER → 只开价格在自身 EMA_slow 上方的品种 | 回撤 −6.8pp |
| 品种分级 | 广度（多少品种在自己均线上方）门槛 | 回撤 −16.8pp、Calmar +34% |

## 9. 周亏补丁

同一品种一周内亏损达到 WEEKLY_LOSS_LIMIT 单 → 该品种本周不再开新仓（下周一恢复）。

## 10. 参数从哪来

```bash
cp config.example.json config.json   # 然后填入你自己的参数
```

仓库**不含**经过长期调优的精确参数值——那属于策略持有人的私有信息。
